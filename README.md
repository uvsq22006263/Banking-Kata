Ce projet est une API bancaire simple développée avec Spring Boot dans le cadre d’un exercice technique de type kata.
L’application permet d’effectuer des opérations bancaires de base telles que le dépôt d’argent, le retrait d’argent ainsi que la consultation de l’historique des opérations d’un compte. 
Chaque opération enregistre des informations importantes comme le type d’opération, le montant, la date ainsi que le solde du compte après l’opération.
